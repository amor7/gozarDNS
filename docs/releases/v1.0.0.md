## اولین نسخهٔ گذر

- یک فایل اجرایی با دو نقش: **hub** (سرور خارج) و **gate** (سرور ایران)
- کنسول مدیریت: داشبورد، مشتری‌ها، پلن‌ها، رسیدها، گیت‌ها، قوانین مسیریابی، گزارش فعالیت، پشتیبان‌گیری و ورود دومرحله‌ای
- پنل مشتری: ثبت‌نام، ثبت آی‌پی، آموزش راه‌اندازی برای هر دستگاه، خرید پلن با کارت‌به‌کارت و ارسال رسید
- DNS هوشمند با مسیریابی بر اساس پلن، پراکسی SNI با شمارش مصرف و محدودیت سرعت برای هر کاربر
- اتصال gate به hub با یک توکن و گواهی سنجاق‌شده؛ فارسی و انگلیسی؛ تم روشن و تیره

**به‌روزرسانی:** روی هر دو سرور (خارج و ایران) بزنید `sudo gozar update`.

<details open><summary>English</summary>

- A single binary with two roles: **hub** (abroad) and **gate** (in Iran)
- Admin console: dashboard, customers, plans, receipts, gates, routing rules, activity log, backups and two-factor sign-in
- Customer portal: sign-up, IP registration, per-device setup guides, buying plans by card transfer with receipt upload
- Smart DNS with per-plan routing; SNI proxy with per-user usage accounting and rate limits
- Gates join the hub with one token over a pinned certificate; Persian and English; light and dark themes

**Update:** run `sudo gozar update` on both servers (hub and gate).
