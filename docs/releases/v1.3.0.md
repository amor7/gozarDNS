## تونل اختیاری بین gate و hub

- برای هر gate از کنسول می‌توانید **تونل** را روشن کنید: ترافیک مشتری‌ها از داخل یک اتصال رمزگذاری‌شده روی پورت ۴۴۳ به hub می‌رود.
- اگر تونل قطع شود، gate خودکار به حالت مستقیم برمی‌گردد و وضعیت تونل در کنسول نمایش داده می‌شود.

**به‌روزرسانی:** روی هر دو سرور (خارج و ایران) بزنید `sudo gozar update`.

---

<details open><summary>English</summary>

- An optional per-gate **tunnel**, switched from the console: customer traffic travels to the hub inside one encrypted connection on port 443.
- If the tunnel goes down the gate falls back to direct mode automatically; tunnel status shows in the console.

**Update:** run `sudo gozar update` on both servers (hub and gate).

</details>
