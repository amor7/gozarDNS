## رفع مشکل وصل‌نشدن gate به hub

- اینترنت ایران اتصال TLS بدون نام سرور (SNI) را قطع می‌کند؛ حالا gate هنگام اتصال به hub نام سرور می‌فرستد و وضعیت gate در کنسول «وصل» می‌شود.

**به‌روزرسانی:** روی سرور ایران بزنید `sudo gozar update`.

---

<details open><summary>English</summary>

- Iran drops TLS connections that carry no server name (SNI). The gate now sends one when it connects to the hub, so gates show as connected in the console.

**Update:** run `sudo gozar update` on the gate.

</details>
