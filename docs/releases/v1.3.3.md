## بررسی اتصال از صفحهٔ خانه

- تست تنظیمات DNS مستقیماً در صفحهٔ خانهٔ پنل مشتری.
- دکمهٔ «بررسی دوبارهٔ آی‌پی»؛ اگر آی‌پی عوض شده باشد، گزینهٔ «ثبت این آی‌پی» نمایش داده می‌شود.

**به‌روزرسانی:** روی سرور ایران بزنید `sudo gozar update`.

---

<details open><summary>English</summary>

- Test your DNS setup right from the portal's home page.
- A "recheck IP" button; if the IP has changed, a "register this IP" option appears.

**Update:** run `sudo gozar update` on the gate.

</details>
