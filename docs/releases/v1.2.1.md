## رفع خطای پرداخت پی‌پینگ

- پی‌پینگ به API نسخهٔ ۳ منتقل شد و پاسخ بازگشتی آن درست خوانده می‌شود؛ پرداخت موفق دیگر «ناموفق» نشان داده نمی‌شود.
- دلیل ناموفق‌بودن پرداخت در لاگ ثبت می‌شود.

**به‌روزرسانی:** روی هر دو سرور (خارج و ایران) بزنید `sudo gozar update`.
