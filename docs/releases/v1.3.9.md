## رفع پر ماندن دایرهٔ حجم با مصرف کم

- با مصرف کم (مثلاً ۲ گیگ از ۱۵۰ گیگ)، دایرهٔ حجم هنوز کاملاً پر دیده می‌شد. دلیلش این بود که سرهای گرد دایره فاصلهٔ کوچک را می‌پوشاندند. حالا اندازهٔ کمان دقیق حساب می‌شود و با هر مقدار مصرف، فاصله در بالای دایره دیده می‌شود.

**به‌روزرسانی:** روی سرور ایران بزنید `sudo gozar update`.

- With little usage (say 2 GB of 150) the data ring still looked completely full, because the ring's rounded ends covered the small gap. The arc is now measured with the ends in mind, so any usage shows a gap at the top.

**Update:** run `sudo gozar update` on the gate.
